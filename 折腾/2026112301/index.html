把废旧安卓手机变成专用设备：一台零成本的 AI Passport

发表于 2026-11-23 更新于 2026-11-26 分类于 折腾 本文字数： 1.5k 阅读时长 ≈ 1 分钟

最近刷到了 FoloToy 的 AI Passport——一块 119 元的透明壳「电子身份卡」，ESP32-C3 加一块小彩屏，可以当工牌、跑社区小游戏、甚至用 AI 编程工具给它写玩法。看着很心动，但转念一想：家里躺着的废旧安卓手机，性能比它强五十倍，这些功能是不是都能用软件复刻？

答案是：能，而且大部分还能做得更好。

AI Passport 是什么

先简单介绍一下这个玩具。它是深圳团队 FoloToy 做的开源可穿戴硬件：透明外壳能看到主板、NFC 线圈和电池，背面直接印着 GitHub 地址。出厂是一张「电子身份卡」——用微信小程序通过蓝牙同步名字、头像、简介和一张全屏图，它就变成一张会亮的工牌。

真正好玩的在后面：官方有个玩法社区，里面已经积累了一千多个社区作品——数码暴龙机模拟器、网络电台、宝可梦对战、贪吃蛇、服务器监控屏、随身电视……接上 Type-C 一键烧录就能换玩法。官方固件开源，所以还能让 Codex、Claude Code 这类 AI 编程工具给它写新玩法，据说上市三周卖了近万台。

缺点也很明显：屏幕小字密、非触屏、一次只能装一个玩法（换玩法等于刷机）、外放音质一般。它不跑大模型——所谓 AI，其实是用 AI 写代码刷进去，本体就是一块几十块钱的开发板。

为什么旧手机能复刻

把 AI Passport 的功能逐项过一遍，会发现旧安卓手机几乎是全面碾压：

AI Passport 功能 旧手机方案 对比
电子身份卡 全屏「工牌模式」APP 更强，还能远程改
NFC 碰一碰 手机自带 NFC，能传名片链接 更强
玩法社区 自建玩法商店，应用内切换 平级，不用刷机秒切
三个按键的小游戏 虚拟按键 + 像素风游戏 平级
小智 AI 对话 直接调语音 API 更强
服务器监控屏 SSH/API 直连 更强
网络电台 / 随身电视 原生 APP 碾压级
待机画面 竖屏常亮相框 / 时钟 更强

手机独占还白送的能力：摄像头、GPS、真电话短信。复刻不了的就两条：50 克的挂脖形态，和几天一充的极端功耗。前者是硬件命，后者对当桌面摆件来说无所谓。

技术方案

我选了 Flutter 来写这个「AI Passport 模拟器」，理由：

  • 像素风 UI 和小游戏是 Canvas 自绘的强项，复刻那种「设备感」最顺手
  • Widget 思维和写网页组件很像，前端经验能平移
  • flutter build apk 一条命令，放 GitHub Actions 云端编译，没电脑也能迭代
  • 一个代码库以后能上 iOS / 桌面

核心的工作量在玩法系统：定义一个「玩法包」格式（JSON 描述界面 + 脚本写逻辑），APP 内嵌解释器加载。这样社区玩法包能一键下载切换，AI 也能直接生成玩法包——体验和原版一样，门槛反而更低。

专用化：让手机变成设备

光有 APP 还不够「设备」，要做 kiosk（专用机）化，四层从易到难：

  1. 全屏沉浸：隐藏状态栏导航栏、竖屏锁定、屏幕常亮
  2. 开机直达 APP：把 APP 注册成桌面（Launcher），监听开机广播——开机直接进 APP，按主页也回 APP
  3. 锁死防误退：屏幕固定、屏蔽返回键、关锁屏、关所有通知
  4. 系统调优：关动画缩放、忽略电池优化、深色主题

关键是这一切完全可逆：注册成桌面只是抢了「主页」权限，原厂桌面还在系统里。APP 设置页留一个「回到手机桌面」入口，再藏个连点三下的彩蛋，想变回手机随时可以。

配套的系统精简也不需要刷机：设置里把预装 APP 逐个「停用」（可逆且干净）、关自动同步、关动画、勿扰常开，三十分钟点完，续航能救回一大截。

后续

原型开工了，流程和之前 iOS 打包一样：代码推 GitHub → Actions 云端出 APK → 手机直接下载安装。等装上真机再写一篇实测。

至于那块 AI Passport——等我把软件版玩明白了，说不定还是会买一块来对比。毕竟「折腾」这件事，从来不是纯理性的。
